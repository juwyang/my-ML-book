### Naive Bayes
for classification.
assumption: features are conditionally independent given the class label.
assume likelihood \(f(x_1, x_2, \ldots, x_p | y) = \prod_{i=1}^p f(x_i | y)\)
application: given height, weight, predict gender.

decision rule: maximize posterior probability.
posterior = likelihood * prior / evidence.
evidence is total probability of features. e.g. f(height=182, weight=75).
